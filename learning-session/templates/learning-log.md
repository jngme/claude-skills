# Learning log

Prose entries, organized by topic, with a chronological session log at the bottom.

Written only by `/learning-commit`. Read on demand by `/learning-session` — never in full, or sessions sprawl.

**This file holds framings, not depths.** What analogy landed, which sentence made it click. How deeply a concept is held lives in `concept-map.md`. Keeping them separate is what lets a session read a 40-line map every time and this file only when it needs the history.

## Rings — goal ordering

Optional. What's worth reaching, in rough order.
